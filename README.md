Smart Self Sustaining Plant Pot for SJSU Intro to Mechatronics Final Project.

This code is designed to control multiple sensors and actuators which include: Soil humidity sensor, light sensor, temperature sensor, water pump, and servo. 

The pot is designed to hold a medium sized plant, with the pot being designed around a compact cherry tomato plant.
The main functions include a self watering function at a certain humidity level within the soil, and a feature that protects the plant from environmental factors when the light level rises to the maximum sensors capacity along with the temperature reaching over 90 degrees farenheit.
